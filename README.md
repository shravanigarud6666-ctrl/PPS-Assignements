# Programming and Problem Solving: Lab Assignments 3–10

Each `.c` file is a separate program. Compile and run one at a time, for example:

```sh
gcc -std=c11 -Wall -Wextra -pedantic 03_calculator.c -o calculator
./calculator
```

| Assignment | Program |
|---|---|
| 03 | Menu-driven arithmetic calculator |
| 04 | Matrix addition and subtraction (up to 10 × 10) |
| 05 | Menu-driven standard string operations |
| 06 | Factorial with and without recursion (0–20) |
| 07 | Student results using an array of structures (marks out of 100) |
| 08 | Swap two numbers using pointers |
| 09 | Copy a file to a new destination file |
| 10 | Month-by-month Gregorian calendar |

For assignment 09, the destination must not already exist; this prevents accidental overwriting. Assignment 05 demonstrates common standard library string operations; the question does not specify an exhaustive list.
